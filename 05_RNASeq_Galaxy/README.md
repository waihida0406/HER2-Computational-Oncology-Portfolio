# Project 5: RNA-Seq Analysis of HER2-Positive Breast Cancer Using Galaxy

## Status
🟡 In Progress

## Objective
To analyze RNA-Seq data from HER2-positive breast cancer samples and identify differentially expressed genes.

## Dataset
- Disease: HER2-positive Breast Cancer
- Organism: Homo sapiens
- Source: GEO / SRA (To be updated)

## Tools Used
- Galaxy
- FastQC
- Cutadapt
- HISAT2
- featureCounts
- MultiQC
- DESeq2

## Workflow
1. Import FASTQ files.
2. Quality assessment.
3. Adapter trimming.
4. Read alignment.
5. Generate gene counts.
6. Differential gene expression analysis.

## Expected Results
- FastQC report
- Alignment summary
- Gene count matrix
- Volcano plot
- Heatmap
