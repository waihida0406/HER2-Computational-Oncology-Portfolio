# Project 3: Molecular Docking of *Ventilago madraspatana* Phytochemicals Against HER2

## Status
🟡 In Progress

## Objective
To investigate the binding affinity of selected phytochemicals with HER2 using molecular docking.

## Target
- HER2 (ERBB2)
- PDB ID: 5TDN

## Tools Used
- PyRx
- Discovery Studio
- PyMOL

## Workflow
1. Prepare protein.
2. Prepare ligands.
3. Perform molecular docking.
4. Rank compounds based on binding affinity.
5. Visualize protein–ligand interactions.

## Expected Results
- Binding affinity
- 2D interaction map
- 3D interaction model
- Docking pose
