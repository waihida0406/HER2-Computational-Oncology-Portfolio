# Project 1: Protein Preparation of HER2 (PDB ID: 5TDN)

## Status
🟡 In Progress

## Objective
To prepare the HER2 (ERBB2) protein structure for molecular docking studies.

## Protein Information
- Protein: Human Epidermal Growth Factor Receptor 2 (HER2)
- Gene: ERBB2
- PDB ID: 5TDN
- Organism: Homo sapiens

## Tools Used
- Protein Data Bank (PDB)
- Discovery Studio
- PyMOL

## Workflow
1. Download the HER2 protein structure from the Protein Data Bank.
2. Remove water molecules.
3. Remove the co-crystallized ligand.
4. Add hydrogen atoms.
5. Save the prepared protein.
