# Project 6: Functional Enrichment Analysis of Differentially Expressed Genes

## Status
🟡 In Progress

## Objective
To investigate the biological pathways and molecular functions associated with differentially expressed genes in HER2-positive breast cancer.

## Tools Used
- DAVID
- Enrichr
- g:Profiler
- Gene Ontology (GO)
- KEGG

## Workflow
1. Import differentially expressed genes.
2. Perform Gene Ontology enrichment.
3. Perform KEGG pathway analysis.
4. Interpret enriched biological pathways.

## Expected Results
- GO Biological Process
- GO Molecular Function
- GO Cellular Component
- KEGG Pathway Analysis

## Future Scope
Integrate transcriptomic findings with molecular docking and molecular dynamics results to identify potential therapeutic targets.
