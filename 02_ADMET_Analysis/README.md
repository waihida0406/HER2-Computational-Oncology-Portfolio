# Project 2: ADMET Screening of *Ventilago madraspatana* Phytochemicals

## Status
🟡 In Progress

## Objective
To evaluate the pharmacokinetic properties and drug-likeness of selected phytochemicals using SwissADME.

## Compound Source
- IMPPAT
- PubChem

## Tools Used
- SwissADME
- PubChem
- IMPPAT

## Workflow
1. Retrieve phytochemicals from IMPPAT.
2. Obtain SMILES from PubChem.
3. Perform ADMET analysis using SwissADME.
4. Evaluate Lipinski's Rule of Five.
5. Select potential lead compounds.

## Expected Results
- Drug-likeness
- Lipinski evaluation
- Pharmacokinetic profile
